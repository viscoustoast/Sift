To run the file, ensure Python is downloaded, alongside all necessary Python libraries.

## To pull the directory from Github:
Open a terminal program, and navigate to the folder you want the directory to be downloaded into. Realistically, any folder is fine, but try to avoid your `/Downloads` folder, as it gets convoluded fast.

**Then, use the following commands:**
```bash
git clone https://github.com/viscoustoast/Sift
cd Sift
```

## Download the required libraries using the requirements.txt file:
**If you have pip3:**
```bash
pip3 install -r requirements.txt
```

**If you have crummy, unreliable Windows downloads:**
```bash
python3 -m pip install -r requirements.txt
```


## To run the file:
Open a terminal program, navigate to the folder the `Sift_Prototype.py` file is located in, and run:
```bash
python3 Sift_Prototype.py
```

# Device requirements:
